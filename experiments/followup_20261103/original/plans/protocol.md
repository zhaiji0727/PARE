**Fixed exploratory follow-up protocol — 42 matched training runs**

Status: fixed before these follow-up training runs. This is a post-hoc hypothesis prompted by the already observed November test results; it is not a preregistered or newly blinded confirmation. The existing 918-image validation set already supported hyperparameter selection. No outcome from this follow-up may be used to rename the original full method, replace its reported test result, or omit an unfavorable configuration.

The machine-readable `protocol.json` is authoritative for configuration IDs, input bindings, run population and contrast coefficients. It fixes 14 configurations and seeds 0, 1 and 2, hence 42 runs. Before launch, record the SHA-256 of both protocol files together with the reviewed implementation and validation report. Subsequent amendments require a new version and a stated reason; preserve this protocol and every affected run.

| Factor | 1 | 0 |
|---|---|---|
| A | Original fine attended vector | Set fine output to the scene vector; retain the second gate output g_f |
| B | Original unaugmented scene+coarse+fine gate aggregate | Unaugmented scene+valid-coarse mean, with denominator 1+valid-coarse count |
| C | Original coarse descriptor detector-positive fraction | Set only c_tf[...,3] to zero on a clone |
| R | Original learned soft reliability | Constant reliability for valid crops, matching legacy sr |
| T | Original h_psi, prototypes and token scale | Normalize original embeddings with no token, matching legacy ty |

When A=0 the scene coefficient remains g_f + max(1-g_c-g_f,0); it is not generally 1-g_c. Preserve both sigmoid gates, all base parameter tensors, masking, normalization and scene fallbacks. C never changes fine descriptors, mu/t/nu, embeddings or extraction caches. B=0 does not remove the fine attended path when A=1. R=0 retains masking and the original constant log-attention term. T=0 does not turn off reliability. Physical crop extraction remains present even when R=T=0.

Run all eight ABC combinations with R=T=1. Also run R/T=00,01,10 at each of ABC=000 and ABC=111. The two RT=11 anchors are shared, not independently counted twice. ABC111_R1T1 is the original full head, ABC000_R1T1 is original cfar_strict, and ABC011_R1T1 is legacy cfar. At either endpoint the R/T switches must match the original sr/ty behavior in addition to the applicable strict flag.

Use only OpenCLIP ViT-B/32 with laion2b_s34b_b79k, the unchanged physics training cache and the fixed content-disjoint split. Train on all 28,759 caption pairs belonging to 8,263 fit images. Evaluate only the 918 first-caption validation queries against all 918 validation images. The larger 9,181-image training cache may supply frozen features for both sets, but no validation pair contributes to loss. The already trained 9,181-image formal heads are not valid checkpoints for this validation comparison. The official 3,688-image test cache, test captions and test metrics are not inputs to this runner.

Training is fixed at AdamW, learning rate 0.002, contrastive temperature 0.03, weight decay 0.0001, batch size 64, 10 complete epochs, float32 and no AMP. There are 450 batches per epoch and a final batch of 23 pairs. Retain the original one-direction diagonal caption-to-image loss, duplicate-image behavior and no early stopping. The learning rate and temperature are the original ViT-B/32 selected pair; there is no new sweep. For every seed, all 14 configurations receive exactly the same base parameter initialization and freshly restored initial pair order, followed by the same independent Python shuffle stream. Do not carry a mutated pair list or RNG state from another configuration. Evaluate the final epoch only; training losses are diagnostic, not a selection criterion.

Validation query order is first occurrence by image in the clean caption loader, taking that image's first caption. Gallery order is the sorted validation row indices of the unchanged cache, matching the original validation evaluator. Score the complete 918-by-918 matrix without positive insertion, candidate truncation or extra positives. Retain the reference torch.argsort descending tie handling and record the backend. R@10 is the primary descriptive outcome; R@1, R@5 and MRR@10 (zero after rank 10) are mandatory secondary outcomes. Metrics are percentages and differences are percentage points.

All contrasts are paired within seed before aggregation. The JSON enumerates every ABC conditional effect, all three average effects, pairwise and three-way interactions, and the full-minus-strict contrast. At both ABC endpoints it enumerates reliability effects with tokens off/on, token effects with reliability off/on, their average effects, interaction and joint RT11-minus-RT00 effect. The nine primary descriptive contrasts are the A/B/C effects with the other two factors on, and the reliability-given-tokens, tokens-given-reliability and joint effects at both endpoints. No contrast is chosen after seeing its sign. Publish each seed's values and differences plus the arithmetic mean and sample standard deviation across the same three seeds. Do not interpret three seeds as independent datasets, add a significance claim from sign consistency, or present only a favorable environment. No hypothesis-test threshold, winner-selection rule or new test-set promotion rule is part of this protocol.

Before formal runs, require endpoint forward and gradient agreement with the frozen original implementation (including full, strict, legacy cfar and all applicable sr/ty endpoints), with absolute tolerance 1e-6 and relative tolerance 1e-5; save maximum errors. Cover dimensions 512 and 768, empty and populated crop sets, padding, and a high-gate-sum case. Test path-specific invariance and preservation of input tensors. The implementation must be external to the frozen training/evaluation sources. All factor fields must be explicit integers 0/1; reject unsupported mixed legacy flags. The parent must review the implementation diff and validation report before launch.

For every run retain protocol/source/input hashes, factor tuple, seed, initial state hash, initial pair-order hash, per-epoch shuffle hashes, optimizer settings, epoch/batch/pair counts, loss history, final checkpoint, complete validation score matrix, ordered query/gallery IDs, caption hashes and ranks. Record failure and retry histories. Retry an infrastructure failure with identical settings; never swap a seed or tune settings to avoid a negative result. A method/numerical repair requires a new documented source version and consistent reruns, not silent replacement. Completion means all 42 prescribed runs are accounted for and all valid results are reported; failed cells remain explicit until resolved. Publish the full protocol and all configurations, metrics, ranks and model bindings; omit protected caption/image contents and machine paths from public projections.

Interpretation is limited to the fixed ViT-B/32 training recipe and previously used validation population. Retrained contrasts include optimization effects, not just an instantaneous attention intervention. A isolates the fine attended-vector path, not all fine information; B can still carry fine semantics. C tests the coarse detector fraction, not all detector use. The strict-vs-full contrast combines three paths. R compares the current soft reliability against constant weights, not against a hard gate; T tests a learned latent descriptor pathway and does not identify physical scattering classes. Positive or negative effects may depend on the other factors. Retain the original five-backbone and scale-test results irrespective of this follow-up's outcome.
